# Student Performance Analysis using NumPy

A beginner-friendly Python project that analyzes student marks using **NumPy**.

## Features

* Calculate overall average marks
* Find the highest-scoring student
* Find the lowest-scoring student
* Find the highest marks in all subjects
* Find the lowest marks in all subjects
* Calculate the percentage of students who passed
* Calculate subject-wise average marks

## Technologies Used

* Python
* NumPy

## Subjects

The project analyzes marks for:

* Mathematics
* Physics
* Chemistry
* Computer Science

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Ritik-Singh7/student-performance-numpy.git
```

### 2. Go inside the project folder

```bash
cd student-performance-numpy
```

### 3. Install NumPy

```bash
pip install -r requirements.txt
```

### 4. Run the program

```bash
python student_analysis.py
```
